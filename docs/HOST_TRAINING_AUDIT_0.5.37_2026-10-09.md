## Терминал и права

Все участники видят один терминал. Оболочка работает на текущем хосте под учётной записью процесса расширения и в репозитории хоста. Команды и Ctrl+C доступны только хосту; удалённые `shellInput` отвергаются протоколом. Вывод восстанавливается после переподключения из ограниченной истории.

Это ограничение ввода терминала. Доверенные участники по-прежнему выполняют Python в ноутбуках; оно не является ОС-песочницей для Python. Полноэкранные TTY-программы и интерактивные пароли требуют обычного локального терминала. Намеренно созданные отдельные ОС-сессии не входят в гарантию POSIX-группы процессов.

- **9 Python bridge-тестов**, **90 VPS-agent тестов** за 34.174 секунды; `ResourceWarning` обрабатывались как ошибки.
- После дополнительной проверки частных папок повторены **136** файловых и регрессионных тестов; все прошли. Это часть полного набора, а не дополнительные уникальные тесты.
- Реальные стандартный CPU и PyTorch пайплайны: файлы конфигурации, Python-модули и данные владельца → обучение → чекпоинт → восстановление модели/оптимизатора → оценка. Проверены Jupyter, общий терминал, detached agent, mesh и режим только VPS, остановка брокера и восстановление вывода без повторного обучения.
- Использованы **PyTorch 2.14.1+cpu**, **jupyter_client 8.10.0**, **ipykernel 7.4.0**. Зависимости установлены отдельно в `/tmp`, без изменения окружения пользователя.

- Длительное выполнение проверено с ускоренными прежними 10/11-минутными таймерами на настоящем Jupyter. Реальное многочасовое ожидание не выполнялось.
- На этой ветке включены CI полного обучения без пропусков и существующая матрица настоящего Extension Host на Windows, Linux, macOS и минимальном VS Code. Удалённая матрица подтверждается собственными результатами, не локальным счётчиком.

## Что остаётся неподтверждённым

- Брокер и Python-агент действительно запущены локально. В части mesh-тестов используется управляемая in-memory граница Trystero; физическая связь двух интернет-компьютеров не проверена.
- Оператор предоставил внешний VPS, но облачная политика содержит пустой TCP allowlist. TCP-прокси недоступен, HTTP-прокси отклоняет SSH CONNECT с **403 Forbidden**. Аутентификация и проверка развёрнутого внешнего VPS не выполнены; обход политики не применялся. Пароль не помещён в проект, артефакты или отчёт.
- Физический GPU, нативное Windows Job Object и локальный нативный VS Code в данном Linux CPU окружении не проверены. Extension Host вынесен в CI.
- Для отдельного compute-агента бинарные датасеты должны существовать в выбранном владельцем `PAIR_NOTEBOOK_WORKSPACE`. Снимок задания содержит исходники и текстовые зависимости, до **4 MiB/256 файлов**. UI не переносит автоматически гигабайтные датасеты и веса. Общие Jupyter/terminal-запуски читают данные из репозитория хоста. Чекпоинты агента доступны в его workspace/job work directory через существующий SSH/файловый доступ.

Установка: `pair-notebook-0.5.37.vsix` на всех участниках. Полный архив содержит исходники, тесты, документацию и агент. Push ветки не публикует GitHub Release автоматически.
